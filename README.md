## ⚙️概述

Sigma Countdown 是一款设计成电影《流浪地球Ⅱ》风格的桌面倒计时贴片。它将以最醒目的方式，清晰地告诉你距离你设定的重要事件还有多少天。

无论是为了激励自己备考、等待某个重要日期，还是提醒自己不要错过某个deadline（截止日期），Sigma Countdown 都能为你提供简洁而有力的视觉提醒。

你可以自由设置：

1. 事件日期：选择任何未来的日期。
2. 事件名称：如“高考”、“生日”、“项目截止日”等。
3. 提醒级别：自定义“还剩”、“距离”等前缀。
